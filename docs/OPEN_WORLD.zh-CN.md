# 探索与建造

[English](OPEN_WORLD.md)

v0.8.0 加入第一版本地单人开放世界。
启动游戏（源码开发时执行 `cargo run --locked`），在主菜单选择 **[5] 探索与建造**。

为世界起名，可选填 0–4294967295 的数字种子。相同种子生成相同的丘陵、泥土、沙土、树木、灌木和地下洞穴。
第一版世界大小为 **2048×256 格**，每格 16 像素；支持创建多份独立存档，点击已有世界继续游玩。

| 操作 | 功能 |
| --- | --- |
| A / D、左右方向键 | 移动 |
| Shift / 空格 | 奔跑 / 跳跃 |
| 按住鼠标左键 | 移除当前图层上的格子 |
| 按住鼠标右键 | 放置所选材料或目录瓦片 |
| 1 / 2 / 3 或材料栏按钮 | 选择泥土、石块、沙土 |
| B / 建造 | 打开建造目录，瓦片无限使用 |
| E / 图层按钮 | 切换背景墙、实体、装饰层 |
| 鼠标中键 | 吸取当前图层的瓦片 |
| H | 回到出生点一列的安全地表 |
| F5 / 保存 | 立即保存 |
| Esc | 关闭目录；目录关闭时保存并退出 |
| 保存并退出 | 保存并返回世界列表 |

材料栏中的泥土、岩石和沙土仍需挖掘获取；建造目录提供素材包内所有瓦片，首版无限使用。
可用分类箭头切换建筑部件、树木植物、街道庭院、店铺、家具、自然地形、砖石和水面。
墙板、屋顶、窗户、门的上下半部、树干、树叶、灌木、花草、围栏、长椅和路灯均可逐格放置。
水面和门部件目前只提供美术，没有新增流体模拟或传送门交互。

背景墙与装饰层不参与碰撞，实体层使用瓦片本身的碰撞定义，木平台支持从下方穿过。
同一格可叠放三层，挖掘只影响选中的图层；新树木和灌木也由这些格子生成，砍掉的树干和叶片会保存。
树叶按相邻格自动连接边缘，包括区块边界。

操作距离为六格，实体地形会遮挡挖掘和建造。材料栏放置的地形需要连接已有地形或有碰撞的建筑瓦片；
目录瓦片可在范围内自由放置，有碰撞的格子不能与角色重叠；
世界底部和边缘受保护。打开设置时不会触发挖掘或移动，界面缩放和场景缩放可以分开调节。

地形按 **32×32 格**区块加载，只渲染镜头附近的区块，远处区块卸载。
格式 2 存档记录种子、地形与植被生成版本、地形改动、各层瓦片的稳定 ID、材料和角色位置。
旧格式 1 可以继续读取，保留原有地形，不新增植被覆盖建筑；首次使用目录建造后升级为格式 2。
缺失素材 ID 会明确报错。升级前可备份存档，旧客户端无法读取格式 2。
每五秒自动保存，退出世界和关闭窗口时也保存。
保存失败时保留正在游玩的世界并显示错误，修复后可以重试；损坏文件、未来版本存档和其他程序改动过的文件不会被悄悄覆盖。
同一份存档只用一个游戏进程打开，当前没有跨进程写入锁。

存档位于游戏数据目录的 `worlds/`：macOS 为 `~/Library/Application Support/Yapshire/worlds`，
Windows 为 `%APPDATA%/Yapshire/worlds`，Linux 为 `$XDG_DATA_HOME/yapshire/worlds` 或
`~/.local/share/yapshire/worlds`。关闭游戏后可备份其中的 JSON 文件；开发时用 `YAPSHIRE_WORLD_DIR` 指定独立目录。
这些文件与地图编辑器、钓鱼存档分开存放。

现有 Club、局域网房间继续使用原来的小镇与地图包，**目前不能多人共同修改生成世界**。
v0.9.0 使用内容包 2.0.0 与协议 5，保留全部 855 个建造瓦片 ID 和旧单人存档。
联机预制地图新增像素沙、水和挖掘；生成的单人世界仍使用可保存的瓦片地形。请配套升级客户端与服务端。
合成、战斗、生存、流体、无限地图和自定义地形内容包尚未实现。

下一阶段的联机结构保持 **Club → Room → 世界**：Club 是服务入口，每个 Room 拥有独立的持久世界，
地表和洞穴是世界内的区域。需要先补齐服务端地形修改校验、材料归属、区块增量同步和世界持久化，
再开放多人共建；目前服务端各房间共用一套不可变地图，临时空房间会被移除。

实现结构、生成器版本约束和原生验收命令见[英文开发说明](OPEN_WORLD.md#implementation-and-native-acceptance)。

植被版本 2 使用细化的树木、灌木组合模板；植被版本 1 保持原有格子布局及已挖除记录。
缺少对应模板或瓦片时会报告错误，不会将已清空的树叶重新生成。
`YAPSHIRE_SMOKE=wilds-tiles-art` 通过本地测试角色截取小镇与码头的实机美术画面，不启动服务器。
