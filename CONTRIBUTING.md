# Contributing

Yapshire is a Rust + Bevy game, a headless server in `crates/yapshire-server`,
shared map/protocol types in `crates/yapshire-shared`, and an alternative
Cloudflare Worker in `server/`.
Start with the [README](README.md) and [development guide](docs/DEVELOPMENT.md).

- Put interface text in the modular `assets/locales/` catalogs and use the
  bundled pixel font. English is the source and fallback; Simplified Chinese
  translations live in `zh-CN/`. See [the translation guide](docs/TRANSLATING.md).
- Keep changes focused. Preserve compatibility with the public Worker when
  changing the shared protocol, and test the game and dedicated server together.
  Add a behavior test for new networking logic.
- Run the checks listed in the README. UI changes also need a real game run;
  compilation alone cannot verify layout, movement or text input.
- Use English Conventional Commits, such as `feat: add named rooms` or
  `fix: preserve chat input when switching focus`. These become Release Notes.
- Do not commit build output, local Wrangler state, secrets, or private chat logs.
- Keep `assets/maps/` compatibility fixtures byte-for-byte unchanged. Content-pack
  image bytes under `assets/packs/` also participate in multiplayer compatibility
  hashes, so automated image optimization excludes both directories. Change pack
  assets only as part of an intentional, versioned content update.
- Use the version preparation script before tagging. Formal CHANGELOG entries
  are generated by the release workflow, not maintained separately from releases.

## Pre-commit checks

Install [pre-commit](https://pre-commit.com/#installation), then enable the hooks
once per checkout and check all tracked files:

```sh
pre-commit install
pre-commit run --all-files
```

The configuration checks JSON (including Tiled maps and tilesets), YAML, TOML,
merge markers, filename case conflicts, and broken symlinks. The same checks run
in pre-commit.ci and the shared GitHub Actions checks used by CI and releases.
Actions pins pre-commit to 4.6.2; hook versions are pinned in
`.pre-commit-config.yaml`.

Code and original artwork are AGPL-3.0-only. Preserve third-party font notices
when redistributing or changing the bundled assets.
